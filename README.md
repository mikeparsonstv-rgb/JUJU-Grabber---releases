# JUJU Grabber

JUJU Grabber © 2026 JUJU VFX. All rights reserved.

A native macOS downloader: Video, Audio, Galleries, Gleaner, Deliveries and Convert in one window.

## Download
Get the DMG from the [latest release](../../releases/latest), open it, drag **JUJU Grabber** to Applications and open it from there.

Needs macOS 26 or later on an Apple Silicon Mac (M1 or newer). The app is signed with a Developer ID and notarized by Apple, so it opens without warnings.

On first run it offers to install yt-dlp, FFmpeg, cobalt, gallery-dl and the bgutil plugin from their official sources.
